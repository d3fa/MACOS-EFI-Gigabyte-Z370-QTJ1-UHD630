My Working EFI partitin from Hackintosh - OpenCore Bootloader
Tested on MacOS Sequoia and older

Hardware:
* CPU: QTJ1 aka Core i9 10980HK ES (Intel i7 9900k)
* MB:  Gigabyte Z370 HD3P
* Video: Intel UHD630 + GTX1070 (disabled in config)
* Built-it Sound: NONE! - i'm using Asus Xonar DX (work fine)
* Network: Intel i219-V

To generate valid SN/MLB/etc run [Macserial](https://dortania.github.io/OpenCore-Post-Install/universal/iservices.html#using-macserial) from /Volumes/EFI/Utilities/macserial/ before you login to your apple account
