My Working EFI partitin from Hackintosh - OpenCore Bootloader
Tested on MacOS Tahoe and older

Hardware:
* CPU: QTJ1 aka Core i9 10980HK ES (Intel i7 9900k)
* MB:  Gigabyte Z370 HD3P
* Video: Intel UHD630 + RTX5070 (disabled in config)
* Built-it Sound: NONE! - i'm using Asus Xonar DX (work fine)
* Network: Intel i219-V
* [CSR8510 A10](https://www.reddit.com/r/hackintosh/comments/1g4z5te/how_to_make_generic_csr_usb_bluetooth_5040_dongle/?rdt=58805) USB Bluetooth 5.0/4.0 Dongle

To generate valid SMBIOS (SN/MLB/etc) run [GenSMBIOS](https://github.com/corpnewt/GenSMBIOS) before you login to your apple account
